🚀 Quick Start

      
Get up and running with tmuxship in less than a minute.


      
1. Install tmuxship

      
cargo install tmuxship


      
2. Choose and apply your theme

      
Preview available themes directly in your terminal:

      
tmuxship theme preview


      
Then add to your ~/.tmux.conf:

      
setenv -g TMUX_SHIP_THEME "rose-pine"

run-shell 'tmuxship apply'


      
3. Reload tmux

      
tmux source ~/.tmux.conf

    


    
    

      
⚡ How It Works

      

        The recommended execution model is tmuxship apply, which runs synchronously once when tmux starts or reloads. It translates your Starship TOML custom styles directly into native tmux status options:
      


      

        

          
            

              Mode
              How it works
              Ideal for
            

          
          
            

              tmuxship apply (Recommended)
              Translates Starship TOML colors into native tmux options at startup. Zero background process overhead, zero flicker.
              Colors, session name, window tabs, host, zoom indicator.
            

            

              #(tmuxship <side>) (Runtime)
              Runs every status-interval, queries tmux environment variables, calls Starship, converts ANSI to tmux format.
              Dynamic data like battery percentage, live git status, weather.
            

          
        

      

    


    
    

      
⚙️ Config File Resolution

      
tmuxship resolves Starship configuration files in the following order of precedence:

      
    
        
  1. --config <path> command-line argument
    2. 
        
  2. TMUX_SHIP_<SIDE>_CONFIG environment variable (e.g. TMUX_SHIP_LEFT_CONFIG)
    3. 
        
  3. STARSHIP_CONFIG environment variable
    4. 
        
  4. --theme <name> flag or TMUX_SHIP_THEME environment variable
    5. 
        
  5. $XDG_CONFIG_HOME/tmux/.<side>.toml or starship.toml
    6. 
        
  6. $HOME/.config/tmux/.<side>.toml or starship.toml
    7. 
        
  7. $HOME/.tmux/.<side>.toml or starship.toml
    8. 
        
  8. $HOME/.config/starship/.<side>.toml or starship.toml
    9.

🎨 Contributing New Themes

      

        Adding a new theme to tmuxship is super easy! Each theme lives in its own directory in the themes/ folder:
      


      
themes/
└── your-theme-name/
    ├── theme.toml      # Metadata, description, author, and color swatches
    ├── starship.toml   # Left status Starship config
    ├── .center.toml    # Window status Starship config
    ├── .right.toml     # Right status Starship config
    └── .full.toml      # Full status bar config


      

        Test your theme locally with cargo run -- theme preview your-theme-name and submit a PR!
